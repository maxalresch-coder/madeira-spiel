# Bilder für die regionalen Quests

Hier kommt pro regionaler Quest **ein Bild** hinein. Der Dateiname muss **genau** so
lauten wie unten (klein geschrieben, Endung `.jpg`). Ist ein Bild da, erscheint es
oben im Quest-Fenster. Fehlt es, wird einfach kein Bild angezeigt.

**Format:** JPG, ca. **1.200 Pixel breit**, Querformat (z. B. 4:3 oder 3:2),
möglichst **unter 300 KB**.

Zu große Bilder oder andere Formate (z. B. `q-cal-1.png`, `q-cal-1.jpeg`) verkleinert
und wandelt das Skript automatisch um:

```bash
cd ~/madeira-spiel && python3 tools/bilder_verkleinern.py
```

Die Originale landen dabei im Unterordner `originale/`.
